## 🎮 About the Game

Eslabong is an action, strategy, simulation, and management game developed and published by shirowita. It entered Early Access on August 24, 2026, for Windows PC. The game combines real-time medieval arena combat with mercenary club management, seasonal leagues, cups, tournaments, and PvE challenges.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Eslabong**. This trainer provides optional advantages for arena battles and club management. It can protect fighters during real-time combat, reduce ability downtime, increase available resources, and accelerate roster development while preserving Eslabong's recruitment, tactical, and seasonal progression systems.

**Target Audience:** Players who want to experiment with classes, abilities, relics, formations, recruitment choices, seasonal progression, and arena tactics without the usual resource or combat limitations.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Eslabong allows direct control of a captain during real-time arena battles. Move carefully to create distance, avoid incoming attacks, line up aimable abilities, and protect vulnerable members of the squad. The trainer's defensive options are most useful when learning positioning and timing.

### Tools & Inventory

Use gold to recruit mercenaries from the dynamic market, buy and sell roster members, and improve the club over multiple seasons. Manage equipment and relics alongside class abilities so each fighter supports a clear team role. Activate resource features before making purchases or reorganizing the roster.

### World & Environment

The game's medieval setting centers on mercenary clubs competing in structured arena events rather than traditional warfare. Progress through recurring seasons, leagues, cups, tournaments, and PvE activities such as Defend the Iron Gate. The Challenge Tower provides asynchronous battles against other players' rosters.

### Combat & Weapons

Choose between directly controlling a captain and setting tactics for autobattle. Real-time combat rewards positioning, timing, target selection, ability use, healing, blocking, resurrection, combos, and battlefield control. Enable health, mana, or cooldown options only when needed to test builds or overcome difficult encounters.
